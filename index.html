Access from Any Device & Online Hosting

You can easily host this entire app online for free so you can access it from your iPhone, Android, iPad, or any computer, anytime.

Option 1 • Instant & Free

GitHub Pages

100% free permanent hosting with your own custom link (e.g. username.github.io/mooncat).

  1. Create a new free repository on GitHub named mooncat-vault.
  2. Push or upload these files (index.html, style.css, app.js, catalog_data.js).
  3. Go to Settings > Pages and enable GitHub Pages on branch main.
  4. Your app is live online within seconds!
Option 2 • Drag & Drop

Netlify or Vercel

Drag this folder into Netlify Drop (app.netlify.com/drop) to get an instant live website URL without needing git.

  • Open your browser to netlify.com/drop.
  • Drag the /Users/melissaruth/Documents/Mooncat folder onto the page.
  • Instantly receive a live shareable URL!
Option 3 • Firebase Hosting

Google Firebase

Deploy using Firebase Hosting CLI. We have pre-configured Firebase support in your project.

firebase init hosting
firebase deploy
